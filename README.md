# بات معامله‌گر کوتاه‌مدت Nobitex

بات اسپات نوبیتکس با ۴ استراتژی کوتاه‌مدت، بک‌تست، حد ضرر/حد سود و فیلتر اخبار.
مستندات API: https://apidocs.nobitex.ir/

## ساختار

```
nobitex-bot/
├── config.yaml          # تنظیمات (کوین‌ها، تایم‌فریم، ریسک، اخبار)
├── requirements.txt
├── .env.example         # NOBITEX_TOKEN را اینجا بگذار (کپی به .env)
├── src/
│   ├── nobitex_client.py  # کلاینت رسمی apiv2 (OHLC/stats/orderbook + سفارش اسپات/OCO)
│   ├── indicators.py      # EMA, RSI, MACD, ATR, Bollinger, Stochastic, ADX, Donchian
│   ├── strategies.py      # ۴ استراتژی + سیگنال اجماعی ورود/خروج
│   ├── backtest.py        # بک‌تستر با SL/TP بر اساس ATR، کارمزد، خروج زمانی
│   ├── screener.py        # رتبه‌بندی و انتخاب بهترین کوین
│   ├── news.py            # Fear&Greed + CryptoPanic + رژیم BTC → گیت ورود
│   └── trader.py          # موتور معامله (ورود مارکت + خروج OCO)
└── scripts/
    ├── backtest_all.py  # بک‌تست همه کوین‌ها + گرید SL/TP
    ├── run_paper.py     # اجرای مجازی (بدون پول)
    └── run_live.py      # اجرای واقعی (با تاییدیه)
```

## استراتژی‌ها (کوتاه‌مدت، بدون هلد)

| # | استراتژی | ورود لانگ | خروج |
|---|----------|-----------|------|
| ۱ | روند EMA+MACD | EMA9>EMA21 و MACD>0 و قیمت>EMA50 و ADX>20 | کراس معکوس / اجماع منفی |
| ۲ | میانگین‌بازگشتی | RSI<32 و برخورد باند پایین بولینگر | RSI>55 یا بازگشت به میانه باند |
| ۳ | بریک‌اوت دانچیان | شکست سقف ۲۰ کندله + حجم بالا + ADX>20 | برگشت زیر میانه بولینگر |
| ۴ | اسکوییز بولینگر | فشردگی باند + خروج رو به بالا + RSI ۵۰–۷۵ | برگشت زیر میانه / RSI>78 |

**ورود نهایی:** حداقل ۲ استراتژی موافق + امتیاز ≥ ۲ + RSI<72 (عدم تعقیب سقف).
**خروج:** حد ضرر ۱.۵×ATR، حد سود ۲.۵×ATR (قابل تیون per-coin)، سیگنال اجماعی، سقف ۹۶ کندل (هلد ممنوع).

## نصب و اجرا

```bash
cd nobitex-bot
pip install -r requirements.txt
cp .env.example .env   # و NOBITEX_TOKEN را بگذار

# ۱) بک‌تست و انتخاب بهترین کوین:
python scripts/backtest_all.py

# ۲) اجرای مجازی:
python scripts/run_paper.py

# ۳) اجرای واقعی (توکن + تاییدیه):
NOBITEX_TOKEN=xxx python scripts/run_live.py
```

## نکات مهم (صادقانه)

- **تاریخچه نوبیتکس محدود است:** تایم‌فریم 15m فقط ~۷ روز، 30m ~۱۰ روز، 60m چند ماه. برای بک‌تست عمیق از 60m استفاده کن.
- **نتیجه بک‌تست واقعی (60m، ژوئیه–سپتامبر ۲۰۲۶):** SOL ≈ +۷٪، ETH ≈ +۳.۸٪ (با تیون SL/TP)، BTC و DOGE منفی. یعنی استراتژی در همه بازارها سودده نیست — اسکرینر و تیون per-coin ضروری است. در روند صعودی قوی، بای‌اند-هلد بهتر عمل می‌کند؛ مزیت بات در خروج منضبط با حد ضرر است.
- **اخبار:** بدون کلید CryptoPanic فقط Fear&Greed + رژیم تکنیکال BTC فعال است. برای تحلیل تیترها، توکن رایگان cryptopanic.com بگیر و در config بگذار.
- **ریسک:** با `dry_run` و مبالغ کوچک شروع کن. ریسک هر معامله ۱٪ و سقف ضرر روزانه ۳٪ پیش‌فرض است.
